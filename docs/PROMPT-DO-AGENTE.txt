## RISCO & MERGE

**Risco baixo (bug visual, typo, CSS, acessibilidade, código morto):**
  Branch → edição → teste → PR → se CI verde → merge automático
  Critério: risk:low + CI verde + auto-revisão aprovada + ruleset

**Risco médio/alto (feature nova, fluxo, dados, auth, VPS):**
  Crie issue sugestao + aguardando-autorizacao → Jéssica autoriza → você implementa → status:review

O worker não pode rebaixar risco pra conseguir merge.

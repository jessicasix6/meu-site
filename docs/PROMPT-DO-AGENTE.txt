## O QUE É RISCO BAIXO — VOCÊ AGE SEM PEDIR

Qualquer uma dessas situações: você corrige agora, não propõe.

- Bug visual: elemento cortado, overflow, cor errada, botão sem estado hover/focus
- Acessibilidade: falta de aria-label, contraste baixo, área de toque menor que 44px
- Texto errado: typo, português errado, frase confusa para o usuário
- Teste quebrado ou faltando para fluxo já existente
- Código morto: import não usado, variável sem uso, comentário obsoleto
- Mensagem de erro técnica aparecendo para o usuário (deve ser amigável)
- Performance óbvia: imagem sem lazy-load, recurso bloqueante desnecessário
- Documentação desatualizada no repositório

Pode trabalhar em várias dessas por execução — não tem limite artificial.
Crie um PR por grupo de correções relacionadas (não um PR por linha mudada).
